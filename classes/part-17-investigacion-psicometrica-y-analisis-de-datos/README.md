# Parte 17 — Investigación psicométrica y análisis de datos

**Nivel:** avanzado · **Duración estimada:** 4-5 semanas · **Clases:** 10

## De qué trata

Cómo se diseña un estudio de validación, se simula, se analiza y se informa de forma reproducible.

## Por qué importa

Una buena idea de instrumento sólo se vuelve confiable con un estudio bien hecho.

## Según tu papel

- **Si construyes o aplicas instrumentos:** Tamaño muestral, datos faltantes, bootstrap, DIF, preregistro y meta-análisis.
- **Si eres evaluado o recibes resultados:** Te permite juzgar si el estudio que respalda un instrumento merece confianza.

## Al terminar esta parte podrás

- Planificar un estudio de validación.
- Redactar un informe que cualifique cada afirmación.

## Cómo estudiarla

Requiere las partes 02 a 06.
